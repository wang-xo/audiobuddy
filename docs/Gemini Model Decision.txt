Gemini Model Decision

Decision date: 11 October 2026
Review date: 1 April 2027

Decision:

Use gemini-3.8-flash as the primary AudioBuddy summarization and transcription
model.
Use gemini-3.6-flash only as the fallback for transient 3.8 failures.

Reasoning:

Google deprecated gemini-3.7-flash on 8 October 2026 and replaced it with
gemini-3.8-flash. Google documents gemini-3.8-flash as the current stable Flash
model, with support for audio input and text output. Keeping gemini-3.6-flash
as the fallback retains the previously reliable model as an independent recovery
path for transient primary-model failures.

The replaced 3.7 model had returned InternalServerError during controlled live
testing on 1 September 2026, while 3.6 completed the same summaries. The new
order removes a deprecated model string and preserves that demonstrated 3.6
fallback behavior.

Review this order on 1 April 2027, or sooner if controlled AudioBuddy tests
show a persistent Gemini 3.8 Flash reliability or quality problem.
